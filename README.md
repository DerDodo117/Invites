# Coffee-Date-Einladung

Selbst-contained Einladungsseite (`index.html`, keine externen Abhängigkeiten, funktioniert offline und auf jedem Static-Host).

## Inhalt

1. Frage: Hast du am Samstag, 21.11.2026, nachmittags Zeit? – „Nein“ flieht vor der Maus, „Ja“ löst Konfetti + humorvolle Reaktion aus.
2. Zeitauswahl: Samstag, 21.11.2026, alle 30 Minuten von 13:00 bis 17:30 Uhr.
3. Danke & Vorfreude inkl. Treffpunkt: „The Beautiful & the Brilliant“ – Café im Kleidermagazin, Ladage & Oelke, Alter Wall 22, 20457 Hamburg.
4. Benachrichtigung: Nach der Zeitauswahl öffnet sich automatisch eine vorbefüllte Mail (mailto:) an luca.dorendorf@outlook.de mit dem gewählten Termin; zusätzlich Button zum erneuten Senden.

Farbschema: Off-White mit braunen und grünen Akzenten (Barbour-Look) inkl. Tartan-Streifen.

## Als Link veröffentlichen (GitHub Pages)

1. `index.html` liegt im Root dieses Repos.
2. Auf GitHub: **Settings → Pages → Source: Deploy from a branch → Branch `main`, Ordner `/ (root)`** speichern.
3. Der Link lautet dann: `https://<github-benutzername>.github.io/<repo-name>/`
